# Demo Script

## Minute-by-Minute Stakeholder Walkthrough

### 0:00 - 1:00: Overview & Dashboard
- Welcome and context setting.
- Show the Dashboard: highlight real-time stats, response time charts, and message volume over the last 30 days.

### 1:00 - 2:00: Inbox & Real-time Chat
- Navigate to the Inbox.
- Demonstrate selecting a conversation.
- Show message bubbles (text, media).
- Send a test message and explain delivery ticks (Sent -> Delivered -> Read).

### 2:00 - 3:00: Contact Management
- Move to Contacts page.
- Demonstrate filtering (e.g., active contacts only).
- Search for a specific contact.
- Click through to the Contact Details view and show activity history.

### 3:00 - 4:00: Templates & Automation
- Show the Templates section.
- Open the Template Builder and demonstrate live preview and interactive buttons.
- Briefly show the Automation canvas.

### 4:00 - 5:00: Polish & Q&A
- Toggle Dark Mode to demonstrate the polished UI.
- Explain the responsive design (open sidebar, collapse sidebar).
- Discuss future roadmap (API integration, E2E tests).
- Open floor for questions.
